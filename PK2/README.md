# PK2

Статическая версия To-Do List на React для GitHub Pages и обычного статического хостинга.

## Возможности

- добавление, редактирование и удаление задач
- фильтр и сортировка
- отметка выполнения
- очистка выполненных задач
- ручная перестановка карточек
- сохранение задач в `localStorage`
- просмотр текущего JSON по адресу `./api/`
- статический JSON-файл по адресу `./api/tasks.json`

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Для публикации на статическом хостинге загружайте содержимое папки `dist`.
